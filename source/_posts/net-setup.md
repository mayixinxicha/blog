## 先把丑话说在前面

这篇**不教怎么选出口**。线路订阅、独享 IP、自建 VPS 各要花多少钱、不订 AI 的日常用法哪档够用，另有一篇[《看剧、刷视频、查资料：日常访问海外网站，不订 AI，三档预算哪档够用》](/p/budget/)算给你看；要订 AI 怎么选档，系列第四篇会专门讲（筹备中，标题定稿后补链接）——这里都不重复。

这篇**不解决"换了 IP 账号还是被封"**。工具只管把路修通；路修通了账号照样被封，那是环境干不干净的问题，另见[《换了 IP，账号还是被封：三层排查，改错一层等于白改》](/p/ban-check/)和[《IP 干不干净怎么看：四步自查，全用免费工具，查完知道要不要换》](/p/ip-check/)。

这篇也**不保证你看完就不被封**。所有客户端只能做到"连上"，做不到"干净"。

**写给谁**：想动手把客户端配起来的人——四端里至少有一台还没配好。
**不适合谁**：只想看视频不想读图的，这篇的价值有限。

## 第 1 节 · 安卓：v2rayNG 从零到连上（教学样板）

> 前置：一部安卓手机 + 一份可用订阅（服务商后台复制的那条链接）
> 耗时：约 10 分钟
> 卡住看哪张图：图2（未备案警告）、图8（授权弹窗）

### 第 1 步：下载——只认官方仓库

v2rayNG 的安装包只在它的 [GitHub releases 页](https://github.com/2dust/v2rayNG/releases)发布（✓官方）。页面上如果挂着 **Pre-release** 标签，那是预览版，往下拉找不带这个标签的最新正式版；哪天顶上那条不挂标签了，说明它已经转正，直接下顶上那条就可以。别从任何网盘、任何"打包分享"下载——安装包被二次打包夹带私货的案例并不少（⚠️未测）。

![图1｜v2rayNG 官方 releases 页：认准地址栏和 Pre-release 标签——挂标签的是预览版，正式版往下拉](/images/2026-11/net-setup/fig01-gh-releases.webp)

注意：这里有一个一定会遇到的分叉——v2rayNG 在 GitHub 和 Google Play 是**两个不同签名的版本**，装了其中一个，另一个无法覆盖安装（✓官方，见 [2dust 仓库 README](https://github.com/2dust/v2rayNG)）。装了哪个渠道，以后升级就一直用哪个渠道，来回换只会反复卸载重装。Play 上搜不到就以 GitHub 为准，功能没有差别。

**下载卡住了怎么办**

✅实测：GitHub releases 页国内直连能打开——这篇所有截图都是直连拍的，就是慢，几十 MB 的包等它下完就行。等不起：切手机流量再试，蜂窝网络直连 GitHub 的成功率比家宽高（✅实测，图1 就是手机直连打开的）；还不行就深夜或清晨错峰（⚠️未测）。网上各种"GitHub 加速镜像"本文不提供具体地址——镜像站无法验证安装包有没有被篡改，而且死得快。真要用第三方镜像，装完第一件事：核对版本号与官方 releases 页显示的一致，对不上就删掉重下。

### 第 2 步：安装——"未备案"警告是常态

国产系统（鸿蒙、各定制 UI）的安装器大概率提示"应用未备案，存在风险"。GitHub 官方仓库的包没有在国内应用商店备案，走这个提示是流程的一部分，不是包有问题。确认来源是第 1 步的官方 releases 页，点弹窗里的"了解风险"进详情页，勾选"已了解此应用存在风险"，底部的"仍然安装"才会变亮。

### 第 3 步：导入订阅

首次打开是空的，正常。点右上角 **➕**，选"**从剪贴板导入**"（订阅链接提前在服务商后台复制好），导入后点一下更新。

成功的标志：节点列表从空变满。如果列表没出来，九成是链接没复制全，回服务商后台重新复制整条。

订阅链接**永远只从你的服务商后台复制**——别人发你的"现成链接"不要用。二手链接被大量转发后，节点被墙、账号被停的案例都见过（⚠️未测）。

### 第 4 步：选节点、连接

节点列表先看地区再看名字——先随便选一个近地区的，延迟是测速出来的，连上之后再拿它比才准。单击选中节点，点底部连接按钮。

![图7｜节点列表：还没连，先看地区；右边数字是测速结果，连上之后再拿它比](/images/2026-11/net-setup/fig07-node-list.webp)

第一次连接会弹系统级"**VPN 连接请求**"，点确定。这个弹窗只出现一次，误点了"取消"要去系统设置里找回（设置页顶部搜索框搜"VPN"就能找到）——弹窗里那句"在 VPN 处于活动状态时，您的屏幕顶部会显示钥匙图标"，其实已经把验收标准写在上面了。

连接成功的标志有两个，缺一不可：App 内状态翻转（底部按钮从 ▶ 变成 ■、文字变成"已连接"）+ 状态栏出现 VPN 小钥匙图标。

### 第 5 步：验收

手机浏览器打开 [ip.sb](https://ip.sb)，显示的应该是节点所在地区，不再是你的本地运营商。

![图10｜验收：浏览器里看到的已经是节点地区的 IP，不再是本地运营商](/images/2026-11/net-setup/fig10-verify-ip.webp)

到这里能上网了。但能上网不等于环境干净——干不干净怎么查，第 5 节验收完再说。

> **卡住了怎么办**：跳到[第 6 节《五种连不上》](#第-6-节-·-五种连不上（按出现频率排，各给一句指向）)，对照症状找。不指向任何群、任何客服。

节末备选：**[ClashMetaForAndroid（CMFA）官方仓库](https://github.com/MetaCubeX/ClashMetaForAndroid)**——另一款主流开源安卓客户端（mihomo 内核，与 v2rayNG 的 Xray 内核不同源），订阅大多通用，仍在维护但发版节奏慢（✓官方），v2rayNG 用不顺再换它。

## 第 2 节 · iPhone：Shadowrocket（小火箭），门槛在 App 之外

> 前置：**外区 Apple ID**（什么叫外区，锚点表里有定义）+ 一份可用订阅 + 约 3 美元（美区标价 2.99，一次买断；各区略有差异，以商店页面为准）
> 耗时：约 10 分钟（不含注册 ID 的时间）
> 卡住看哪张图：图14 / 图16（两道授权）
> 最常卡的一步：全局路由默认停在"配置"，要改成"代理"（第 4 步）

### 第 1 步：把 App 买下来——这道门槛绕不过

Shadowrocket 是付费 App（美区标价 2.99 美元，一次买断；各区定价略有差异，本文这单是繁体中文区账号，以你商店页面标价为准），而且**你的 App Store 里搜不到它**——买它需要一个外区的 Apple ID。还没有的话，先去把 ID 办了，注册流程见[《美区 Apple ID 注册实测》](/p/appleid/)。美区商店页面：[Shadowrocket](https://apps.apple.com/us/app/shadowrocket/id932747118)——直链开的是美区页，你登录哪个区的 ID 就显示哪个区的标价。

已经买过的账号最省事：App Store 里显示云朵图标，点一下免费重装，一个账号全家设备通用。

![图11｜App Store 搜 shadowrocket：这单是繁体中文区商店，顶部三张是第三方买的搜索词广告，不是官方推荐](/images/2026-11/net-setup/fig11-appstore.webp)

注意：搜索页顶部那三张（截图里是 relyvpn.com 的"保護隱私""福利模式 無限流量""優質專線一鍵即達"）是第三方买的搜索词广告，不是 Apple 推荐，也不是 Shadowrocket 官方——它们投的就是"shadowrocket"这个词，点进去是另一家的产品。往下滑，认开发者那一行写着 Shadow Launch Technology 的才是。

![图12｜详情页右上角是云朵图标：已购账号点它直接重装，不再收费](/images/2026-11/net-setup/fig12-cloud-icon.webp)

**先说不选谁**：

- **Quantumult X**：功能强，但规则要自己写，学习成本对新手不友好；
- **Stash**：界面漂亮，中文教程少，出了问题很难搜到答案；
- **sing-box 官方 iOS 版**：商店版本更新偏慢；
- **Hiddify**：对不同订阅的适配参差。

四个都各有长处，但对"照着做能通就行"的读者，小火箭是最省事的那个（⚠️未测：以上是使用感受，不是横向评测结论）。

### 第 2 步：导入订阅

打开 Shadowrocket → 右上角 **➕** → 类型选 **Subscribe** → 粘贴链接 → 右上角保存。配置出现在首页列表即成功，和安卓的逻辑一模一样。

![图13｜添加节点表单：类型选 Subscribe，粘贴从服务商后台复制的链接（订阅链接已打码）](/images/2026-11/net-setup/fig13-add-subscribe.webp)

列表里如果混着"打不开网站请从官网跳转""无法订阅请重新复制导入"这种名字的条目（图18 左图底部就有两条）——那不是线路，是服务商塞进订阅的引导项，协议标注看着和真节点一样是 VLESS，选它只会把你导回某个网页。真节点长"香港 1""香港 2"这样。

### 第 3 步：两道授权，都只出现一次

iPhone 的授权比安卓多一道，共两道：

1. 首次启动弹"**允许 Shadowrocket 使用无线数据**"——允许；
2. 第一次点连接，先弹 App 内的"**安装 VPN 配置文件**"，紧接着弹系统级的 **"Shadowrocket"想添加 VPN 配置**——都点允许。

两道授权误点了任何一个，都要去 **设置 → 通用 → VPN 与设备管理** 手动找回，别习惯性点"不允许"。

### 第 4 步：连上

首页**全局路由**默认是"配置"——✅ 实测：要手动改成"**代理**"才能正常用，保持默认连不上（右边那张顶部显示的"代理"就是改完后的状态）。改完点顶部连接开关。开关变蓝 + 状态栏出现 VPN 徽标 = 连上了。首页顶部"全局路由"下面那行"**连通性测试**"，点一下等数字出全——数字只是参考，能通就行。

## 第 3 节 · Windows：Clash Verge Rev，装完记得把两个模式都打开

> 前置：一台 Windows 电脑 + 一份可用订阅
> 耗时：约 10 分钟

### 第 1 步：下载安装

### 第 4 步：两个模式，都要开（全文最容易被坑的一步）

首页"网络设置"卡片里是**系统代理**和**虚拟网卡模式**两个模式按钮，每个按钮下面是它自己的开关，**两个都要开**：先点按钮切过去，再把下面的开关打开。装完默认是关的，图21 那句"系统代理已关闭"就是初始状态。

注意：很多老教程教你去开"TUN 模式"——新版界面里它已经改名叫**虚拟网卡模式**，按"TUN"三个字母找是找不到的，这不是缺了功能，是改了名。

两者的分工：系统代理只对读系统代理设置的程序生效（主要是浏览器），虚拟网卡模式接管全部流量。**只开系统代理，终端和一部分不认代理设置的软件照样直连。**

### 第 5 步：终端验证（Windows 特有的坑）

浏览器已经能上外网了，但如果你要在终端里跑命令（git、npm 之类），会发现命令还是走的本地网络——**cmd 不吃系统代理**，要手动设。两行，第一行设变量，第二行验证：

```
set HTTPS_PROXY=http://127.0.0.1:7897

```

## 第 5 节 · 三项验收（四端通用，配完必做）

> 前置：任一端已连接
> 耗时：3 分钟
> 卡住看哪张图：本节不带图，三项都在浏览器里现场测

### 验收 1：真出去了

浏览器打开 [ip.sb](https://ip.sb) 或 [ipinfo.io](https://ipinfo.io)。

- **合格**：显示节点所在地区；
- **不合格长这样**：显示你的本地运营商（比如中国电信/联通/移动）——说明根本没走代理，回客户端确认连接状态。

### 验收 2：IP 没漏

浏览器开 [browserleaks.com/webrtc](https://browserleaks.com/webrtc)。部分网站能通过 WebRTC 绕过代理，直接拿到你的真实 IP——**不合格长这样**：页面里出现你的本地运营商 IP。

漏了怎么处理：处置在**浏览器侧**——Firefox 可以在设置里直接关 WebRTC；Chrome/Edge 没有原生开关，装一个 WebRTC 防泄漏扩展，或换 Firefox 再测一次。客户端和系统设置里没有这个开关，别去客户端里找。

### 验收 3：DNS 没漏

浏览器开 [browserleaks.com/dns](https://browserleaks.com/dns) 或 [dnsleaktest.com](https://dnsleaktest.com)。**不合格长这样**：检测结果里出现国内的 DNS 服务器——说明域名解析还在走本地，访问记录可能被运营商看到。

注意一个会误判的坑：**系统代理对终端无效**。macOS/Linux 的 `curl` 和 Windows 的 `cmd` 都不吃系统代理，在终端里验 IP 前要手动设代理变量（Windows 用 `set`，Mac/Linux 用小写 `export`），否则永远显示本地运营商 IP——很多人在这步误判成"漏了"，其实只是没设变量。第 3 节第 5 步、第 4 节"终端验证"小节各有一组对照图。

三项都合格，工具篇的任务就完成了。但**能上网不等于环境干净**——IP 本身干不干净、换了 IP 账号为什么还是被封，已经超出这篇的范围，往下一节看。

{% folding 配完想回查？全文的五个坑都在这 %}

- **安装时弹"应用未备案"** → 不是包有问题，是流程的一部分——确认来源是官方 releases 页后照弹窗走（第 1 节第 2 步，图2/图3）；
- **iPhone 连不上** → 全局路由默认停在"配置"，要手动改成"代理"（第 2 节第 4 步，图18）；
- **Windows 找不到 TUN 模式** → 新版改名叫"虚拟网卡模式"，而且系统代理和它**两个都要开**（第 3 节第 4 步，图24）；
- **终端里 git/npm 还走本地网络** → cmd 和 macOS 终端都不吃系统代理，要手动设代理变量，且只对当前窗口有效（第 3 节第 5 步图25、第 4 节"终端验证"图33）；
- **Mac 开了虚拟网卡没生效** → 先弹"需要系统服务"那个框，点安装服务、输开机密码；系统大版本更新后这条授权常被重置（第 4 节差异 2，图31）。

这五个是"配置期的坑"，照做就过；连上了但用不了的，是另一类问题，往下看第 6 节。

## 第 6 节 · 五种连不上（按出现频率排，各给一句指向）

1. **订阅导入失败** → 九成是链接没复制全：回服务商后台重新复制整条（有的链接很长，别漏尾部）。对照图6 的成功状态看差在哪。
2. **连上了打不开** → 先换节点再怀疑别的：回代理页测速，Timeout 的直接排除（对照图23）。iPhone 先查全局路由是不是还停在默认的"配置"——要改成"代理"（见第 2 节第 4 步）。换了三四个都不行，可能是线路本身的问题，这篇不展开。
3. **慢** → 节点地区离你越近通常越快，先测速再挑；持续慢换线路，客户端解决不了线路质量问题。
4. **频繁断** → Mac 先查授权是否被系统更新重置（对照图31）；Windows 查图24 的两个模式是不是都还开着。
5. **虚拟网卡模式开了没生效** → Windows：确认开关真的 ON、没被自动回弹；Mac：确认装过系统服务（图31）；都不行就重启客户端再开一次。

**连上了但账号还是被封、IP 干不干净、DNS 和浏览器指纹各怪谁**——这些超出工具篇的范围，按你卡的地方接着读：[《换了 IP，账号还是被封：三层排查，改错一层等于白改》](/p/ban-check/)、[《IP 干不干净怎么看：四步自查，全用免费工具，查完知道要不要换》](/p/ip-check/)、[《网络连上了还是用不了：一张排查表，DNS、时区、浏览器指纹、风控各怪谁》](/p/net-faq/)。

## FAQ

{% folding Q：你是不是卖线路的？ %}

{% folding Q：导入订阅一直失败怎么办？ %}

九成是链接没复制全，回服务商后台重新复制。如果服务商后台本身都打不开，那不是客户端的问题——你还没有可用的出口，先解决"怎么选、怎么买"：日常用看[《看剧、刷视频、查资料：日常访问海外网站，不订 AI，三档预算哪档够用》](/p/budget/)，订 AI 看[《独享 IP 不等于住宅 IP：要订 AI、做账号，一张对照表别买错档》](/p/ip-type/)。

{% endfolding %}

{% folding Q：这一套要花多少钱？ %}

客户端本身免费——唯一例外是小火箭（美区标价 2.99 美元，各区略有差异）一次买断。花钱的大头是线路订阅，这份账按三档预算另有一篇[《看剧、刷视频、查资料：日常访问海外网站，不订 AI，三档预算哪档够用》](/p/budget/)算给你；订 AI 的档位账是另一笔，看[《独享 IP 不等于住宅 IP：要订 AI、做账号，一张对照表别买错档》](/p/ip-type/)。这里不重复。

{% endfolding %}

iOS 上能用的客户端不止一个，但照着图能一次配通的是小火箭；Windows/Mac 用 Clash Verge Rev，是"导入即用"程度最高的；安卓选 v2rayNG 是新手最容易上手的。它们读的是同一条订阅，协议上互相兼容——换客户端不换订阅，费用见 Q4。
